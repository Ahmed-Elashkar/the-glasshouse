# The Glasshouse

A botanical dining house in a restored Victorian conservatory. Thirty-six seats, one sitting, a table among the palms.

## Run locally

```bash
npm install
npm run dev
```

Then open the URL printed in the terminal.

## What’s included

- Home, menu, garden, evenings, and a table-request form
- Seasonal tasting copy and photography
- Reservations stored in the browser (`localStorage`)

## Deploy

This is a TanStack Start app built for Vercel. Connect this repository to [Vercel](https://vercel.com) and deploy — GitHub Pages will not run it, because the site needs a Node server.
